Hướng Dẫn Cấu Hình Hệ Thống

Hệ thống Backend đang chưa kết nối được với kho dữ liệu trên Hugging Face Hub.

Để nhận dữ liệu dự báo tự động thời gian thực từ pipeline AI, vui lòng bổ sung thông tin vào file .env trong thư mục dự án:

# File .env
HF_DATASET_REPO=<username>/<dataset_name>
HF_TOKEN=hf_xxxxxxxxxxxxxxxxxxxx
CACHE_TTL_SECONDS=300

Sau khi lưu file .env, bạn chỉ cần bấm nút "Làm mới" trên Header để nạp dữ liệu trực tiếp.
